# 文体トーン抽出の手順

過去記事（手本にしたい記事）から文体・トーンの特徴を抽出し、`writing_guidelines.md` に反映するための手順。

:::message
サンプル記事本体（`00_rules/style_samples/`）は著作物のコピーのためリポジトリにコミットしない（`.gitignore` 済み）。この手順書と取得スクリプトのみをリポジトリに残す。
:::

## 1. サンプル記事の収集

手本にしたい記事のURLを 3〜5本 選び、取得スクリプトでMarkdown化して保存する。

```bash
node scripts/fetch-style-sample.mjs <URL>
```

- 保存先: `00_rules/style_samples/SAMPLE-xx_<slug>.md`
- 本数の目安: 少なすぎると癖が拾えず、多すぎると分析がぼやけるため 3〜5本。
- 注意: HTML→Markdown変換のため、元記事のプラットフォーム固有記法（Zennの `:::message` など）は失われる。記法の癖まで抽出したい場合は、元の `.md` ファイル（zenn-content リポジトリ等）を直接 `style_samples/` にコピーする方が精度が高い。

## 2. 分析観点（チェックリスト）の定義

抽出する観点を先に固定してから分析する。標準の観点:

| 観点 | 見るポイント |
| --- | --- |
| 文体基本 | 敬体/常体、一人称、読者への呼びかけ方 |
| 構造の癖 | 導入の型（結論先出し/背景から）、まとめ節の有無と型、見出しの粒度・スタイル（体言止めか文か） |
| 段落・文 | 1段落の長さ、1文の長さ、接続詞の使い方 |
| 記法 | コードブロック・箇条書き・表・画像の使い方と頻度 |
| 語彙・言い回し | よく使うフレーズ、避けている表現、カタカナ語 vs 日本語訳の傾向 |

## 3. 記事ごとの分析 → 横断集計

- 各サンプルを観点ごとに分析し、**必ず原文からの引用（実例文）を証拠として添えて** `00_rules/style_samples/analysis.md` に記録する（このファイルも原文引用を含むためコミットしない）。
- 全記事で共通する特徴 → 「文体ルール」の候補にする。
- 記事によってブレる特徴 → ルール化しない。判断に迷う場合は著者に確認する。

## 4. ガイドライン更新案の提案 → 承認 → 反映

- 分析結果を元に `writing_guidelines.md` の更新案を diff 形式で著者に提示し、**承認を得てから**反映する。
- 各ルールには実例（サンプル由来の短い例文、または一般化した例文）を添え、執筆時に模倣しやすくする。

## 5. review_checklist.md への連動

確定した文体ルールをセルフレビュー項目（`review_checklist.md`）にも反映し、「執筆時に守る → レビューで検証する」のループを閉じる。
