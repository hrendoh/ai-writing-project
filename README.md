# AI執筆エージェント プロジェクトテンプレート

このプロジェクトは、Claude CodeなどのAIコーディングエージェントを活用して、ハルシネーションを抑えながら正確な記事を執筆するためのディレクトリ構成テンプレートです。

## 使い方
1. `01_sources/` に、書きたい内容のメモやソースコードなどを自由に配置します。
2. Claude Codeを起動し、「`01_sources/` の情報をもとに、`02_outlines/toc.md` に構成案を作って」と指示します。
3. 構成案に合意したら、「1章ずつ `03_drafts/` に執筆して」と指示し、AIに質問させながら進めます。

## 参照文献の管理（`01_sources/`）
公式ドキュメントや技術記事を記事の根拠として使うときは、以下の手順で整理します。

1. `01_sources/reference_links.md` の一覧表に1行追加し、`REF-01` から連番でIDを振ります（URL・種別・取得日を記入）。
2. `01_sources/references/REF-01_example.md` をコピーして `REF-xx_スラッグ.md` を作り、そのURLから**記事の根拠になる事実と原文引用**を書き写します。
3. 原稿や構成案では `[REF-01]` の形式で出典を示します。

> **なぜ抜粋が必要か**: AIは `01_sources/` に書かれた情報しか使えません。URLを貼るだけでは中身を事実として扱えない（推測で補完するのは禁止）ため、必ず `references/` に事実を書き写してください。
