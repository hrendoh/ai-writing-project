# 目次と構成案（設計図）

AIエージェントと人間が合意した記事の構成案をここに記述します。

## このファイルの使い方
1. **構成作成フェーズ**: 著者メモを元に構成を作ります。この時点で参照文献は不要です。根拠が必要な記述には `🔍 要出典:` で「どんな根拠があれば書けるか」を書き出します。
2. **調査・キュレーションフェーズ**: `🔍 要出典:` の一覧が調査TODOになります。外部文献の抜粋（`REF-xx`）または著者の検証メモ（`NOTE-xx`）で裏付けが取れたら `[REF-xx]` / `[NOTE-xx]` に置き換えます。
3. **構成検証フェーズ**: すべての `🔍 要出典:` が解消（`[REF-xx]` / `[NOTE-xx]` 付与・削除・`💬 経験談` と明示のいずれか）されたら執筆に進みます。

### 根拠ステータスの凡例
| 表記 | 意味 |
|------|------|
| `🔍 要出典: <必要な根拠>` | 未調査。どんな根拠があれば書けるかのメモ |
| `[REF-xx]` | 外部文献の抜粋（`references/REF-xx_*.md`）で裏付け済み |
| `[NOTE-xx]` | 著者自身の検証メモ（`notes/NOTE-xx_*.md`）で裏付け済み |
| `💬 経験談` | 著者の経験・意見として書く（出典不要と人間が合意済み） |
